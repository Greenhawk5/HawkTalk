# Code of Conduct

## Our standard

HawkTalk is intended to be a respectful and constructive technical project.

Examples of positive participation include:

- being respectful and professional,
- focusing technical feedback on code, documentation, and ideas,
- explaining disagreements with evidence,
- helping newcomers understand the project,
- assuming good intent while still addressing concrete problems.

Unacceptable behavior includes:

- harassment or threats,
- personal attacks,
- discriminatory or hateful conduct,
- deliberate disruption,
- publishing private or sensitive information,
- malicious interference with project infrastructure or users.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent restrictions from project participation.

## Reporting

For security issues, follow [SECURITY.md](SECURITY.md) and report privately.

For general conduct concerns, use a private GitHub communication channel with the maintainer when necessary.
